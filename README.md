## Deskripsi Proyek

Proyek ini dibuat untuk memenuhi tugas Praktikum 4 mengenai *CSS Layout*, penerapan elemen semantik HTML5, teknik *float* dan *clearfix*, serta pembuatan struktur halaman web yang mencakup:

1. `home.html` (Beranda dengan Sidebar Widget)

2. `artikel.html` (Halaman Daftar Artikel)

3. `about.html` (Halaman Tentang Saya)

4. `kontak.html` (Halaman Form Kontak)

5. `lab4_box.html` (Latihan Box Element & Float)
